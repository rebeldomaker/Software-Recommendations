# Software-Recommendations
Text fil archive for essential software i often recommend to friends and colleagues from school. Also for myself to easily copy-paste on new installed OSes any handy software.

## Linux Software
These are the essencials I always install on any freshly installed new GNU/Linux distro on a PC. 

### CLI
```
sudo apt install nala doas ranger btop lynx rms bpytop git wget fish tealdeer clamav cpufetch hyfetch fastfetch cmatrix hollywood neovim lolcat
```

### GUI
```
sudo apt install krita bleachbit mousepad gitg abiword konsole vlc atril clamtk audacity stacer notepadqq
```

### Misc
```
sudo apt install conky
```
